# 꿀뷰 출처 통계 — 인수인계

**현재 버전 v1.2 · 2026-09-29**

꿀뷰 폴더(`Pictures\꿀뷰`)의 사진이 원본(`D:\01.메인`) 바로 아래 어느 폴더에서 왔는지 세는 크롬 웹앱(PWA).
단일 `index.html`, 빌드 없음. 외부 의존은 Pretendard 폰트(CDN) 하나뿐.

## 파일
`index.html` · `manifest.json` · `sw.js` · `icon-192.png` · `icon-512.png` · `icon-512-maskable.png`
이후 수정은 `index.html` 만 올리면 된다 (sw.js 는 네트워크 우선, 캐시 이름 고정 `kkul-source-shell`).

## 동작
1. **꿀뷰 폴더 훑기** — 이미지 확장자만, 경로·크기·수정시각. 파일은 열지 않는다.
2. **원본 목록** — 원본 폴더 전체를 같은 방식으로 훑어 IndexedDB 에 보관 (첫 실행 20~40분).
3. **대조** — 크기가 같은 원본만 후보.
   - 이름·크기·수정시각이 모두 같으면 바로 확정 (윈도 복사는 수정시각을 유지한다)
   - 아니면 지문 비교: 크기 + 앞 256KB + 뒤 256KB 의 SHA-256
4. **판정** (`resolve`)
   - `ok` 내용이 같은 원본이 한 폴더에만 / `dup` 여러 폴더에 (파일명+폴더 목록)
   - `guess` 내용 일치는 없지만 **같은 파일명이 한 폴더에만** 있음 (v1.1 — 회전·보정·다시 저장된 사진). 폴더 집계에 포함, 막대에서 옅은 색
   - `etc` 그 밖. `why` = `none`(같은 이름도 없음) / `many`(같은 이름이 여러 폴더) / `root`(원본 최상위에만)
   - 파일명 비교는 대소문자 무시 (윈도 기준)

## 저장 (IndexedDB `kkul-source` / store `kv`)
| 키 | 내용 |
|---|---|
| `hT` `hO` | 폴더 핸들 (꿀뷰 / 원본) |
| `index` | `{gen, builtAt, root, files:[[경로,크기,수정시각]], stat}` — `stat` 은 v1.1: 폴더 수, 사진 아닌 파일 수·확장자별, 못 읽은 폴더·파일 수와 예시 30개 |
| `fpO` | 원본 지문 캐시 `"경로\|크기\|수정시각" → 지문` |
| `results` | 꿀뷰 사진별 판정 `"경로\|크기\|수정시각" → {st, tops, why, gen, lv, seen, name}` |
| `colors` | 폴더 → 색 칸 번호 (순위가 바뀌어도 같은 폴더는 같은 색) |
| `settings` `last` | 자동 재스캔 여부 / 마지막 갱신 |

## 증분 갱신 규칙 — 건드릴 때 주의
- `ok`·`dup` 은 다시 안 본다. `guess`·`etc` 는 원본 목록이 새로 만들어지거나(`gen`) 판정 규칙 버전(`LOGIC`, 지금 2)이 바뀌면 다시 본다.
  v1.0 결과는 `lv` 가 없어서 v1.1 첫 갱신 때 기타만 원본 재스캔 없이 다시 판정된다.
- 중단하면 거기까지 판정한 것은 저장된다 (v1.0 은 문구만 그렇게 말하고 실제로는 버렸다 — v1.1 에서 고침).
- 폴더·파일 읽기 실패는 조용히 건너뛰지 않고 `stat` 에 센다. v1.0 은 조용히 건너뛰었다.
- `seen` = 그 사진을 처음 본 **갱신 시작 시각**. `seen > index.builtAt` 인 기타가 있으면
  "원본에 새 폴더가 생겼을 수 있다"로 보고 자동 재스캔(설정에서 끌 수 있음).
  ⚠ `seen` 을 판정 시각으로 바꾸면 첫 실행 직후 곧바로 재스캔이 한 번 더 돈다.
- 재스캔은 한 번의 갱신에서 최대 1회 (`rescanned` 플래그).

## 함정
- 폴더 권한은 **클릭 직후에만** 물을 수 있다. 두 폴더를 연달아 물을 때 두 번째가 실패하면
  "한 번 더 눌러 달라"는 안내가 나온다. 권한 창에서 "방문할 때마다 허용"을 고르면 다시 안 묻는다.
- 테스트 환경(리눅스 헤드리스 크로미움)의 OPFS 는 **한글 폴더 이름을 제대로 못 다룬다**
  (폴더가 사라지고 안의 파일이 위로 올라온다). 테스트용 가짜 폴더는 영문으로 만들 것. 실제 윈도에서는 문제 없음.
- 테스트 창구: `window.KS` = `{S, refresh, render, put, get, useHandles(꿀뷰핸들, 원본핸들)}`
